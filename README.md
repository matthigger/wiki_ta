# wiki_teach

Instructions for course TAs, published with
[MkDocs Material](https://squidfunk.github.io/mkdocs-material/) to GitHub
Pages at <https://matthigger.github.io/wiki_teach/>.

Pages live in `docs/`; the sidebar order is `nav:` in `mkdocs.yml`. Pushing
to `main` rebuilds the site (`.github/workflows/deploy.yml`). See
`docs/editing.md` for how TAs edit.

Local preview:

    pip install -r requirements.txt
    mkdocs serve
